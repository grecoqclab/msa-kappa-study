0. 判定資料同步設定

判定紀錄會即時同步到一份 Google 試算表，3 位操作員不論用哪台電腦，只要貼同一個網址，資料就會自動彙整在一起，網頁裡也能直接看到 3 個人的即時總進度。
設定方式：Google 試算表 →「擴充功能」→「Apps Script」→ 貼上對應程式碼 →「部署」→「新增部署作業」→ 網頁應用程式（執行身分：我；誰可以存取：任何人）→ 複製取得的網址貼在下方。

            用這裡把本機的照片資料夾匯入一次——可以選最上層同時包含 Adhesion/ 與 Resolution/ 的資料夾，

            把它跟照片一起 push 到 GitHub repo 的 images/ 資料夾內，之後所有人開啟網頁就會自動載入這 60 張照片。
